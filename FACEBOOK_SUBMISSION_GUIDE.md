### Step 1: Fix Missing Fields

1. **Create App Icon:**

   - Find **"User data deletion"**

   - Go to **Settings** → **Basic**
   - Update **"Site URL"** from ngrok URL to: `https://focusrobin.lt`

   - Go to **App Review** → **Permissions and Features**
   - Add the testing instructions provided above

### Step 2: Verify All Fields

Go through the checklist above and make sure all fields are filled.

### Step 3: Submit for Review

1. Go to **App Review** → **Permissions and Features**
2. Find the permissions you're requesting (`email`, `public_profile`)
3. Click **"Request"** or **"Submit for Review"**
4. Fill out any additional forms
5. Submit!

## 🚀 After Submission

1. **Wait for Review:** Usually takes 1-7 business days
2. **Check Status:** Go to **App Review** → **My Submissions**
3. **If Approved:** Switch app to **Live Mode** (toggle at top of dashboard)
4. **If Rejected:** Check feedback and fix issues, then resubmit

---

## 📞 Need Help?

If Facebook rejects your submission:
1. Check the rejection reason in **App Review** → **My Submissions**
2. Fix the issues mentioned
3. Resubmit

Common rejection reasons:
- Missing privacy policy (you have this ✅)
- Missing data deletion instructions (we're adding this ✅)
- Invalid redirect URI (make sure it's `https://focusrobin.lt/api/auth/callback/facebook`)
- App not working (test it thoroughly before submitting)
