# Quick Fix for Prisma 7 on VPS

## Option 1: Update Files Directly on VPS (Quick Fix)

If you have the source code on your VPS at `/var/www/focusrobin`, run these commands:

```bash
# 1. Navigate to your project directory
cd /var/www/focusrobin

# 2. Update schema.prisma - Remove the url line from datasource
sed -i '/^  url.*env("DATABASE_URL")/d' prisma/schema.prisma

# 3. Verify the change (should show only "provider = "postgresql"")
grep -A 2 "datasource db" prisma/schema.prisma

# 4. Update package.json to use Prisma 7.3.0
sed -i 's/"prisma": "\^6\.19\.0"/"prisma": "^7.3.0"/' package.json
sed -i 's/"@prisma\/client": "\^6\.19\.0"/"@prisma\/client": "^7.3.0"/' package.json

# 5. Make sure prisma.config.ts exists (it should already be there)
# If not, create it with the content shown below

# 6. Rebuild the Docker image
docker compose build app

# 7. Push to Docker Hub (if you want to update the image)
docker tag focusrobinsite-app:latest hariharan11111/focusrobin-app:latest
docker push hariharan11111/focusrobin-app:latest

# 8. Pull the new image and restart
docker compose pull app
docker compose up -d app

# 9. Now run the migration
docker compose exec app npx prisma migrate deploy
```

## Option 2: Manual File Edit on VPS

If you prefer to edit manually:

```bash
cd /var/www/focusrobin

# Edit schema.prisma
nano prisma/schema.prisma
# Remove line 8: url      = env("DATABASE_URL")
# Keep only: provider = "postgresql"

# Edit package.json
nano package.json
# Change "prisma": "^6.19.0" to "prisma": "^7.3.0"
# Change "@prisma/client": "^6.19.0" to "@prisma/client": "^7.3.0"
```

## Option 3: Copy Updated Files from Local to VPS

If you've already updated the files locally, copy them to VPS:

```bash
# From your local machine (Windows PowerShell or WSL)
scp G:\Dev\focusrobinsite\prisma\schema.prisma root@srv1301254:/var/www/focusrobin/prisma/schema.prisma
scp G:\Dev\focusrobinsite\package.json root@srv1301254:/var/www/focusrobin/package.json
scp G:\Dev\focusrobinsite\prisma.config.ts root@srv1301254:/var/www/focusrobin/prisma.config.ts

# Then on VPS, rebuild and restart
cd /var/www/focusrobin
docker compose build app
docker compose up -d app
docker compose exec app npx prisma migrate deploy
```

## Verify prisma.config.ts exists

Make sure `/var/www/focusrobin/prisma.config.ts` exists with this content:

```typescript
// This file was generated by Prisma and assumes you have installed the following:
// npm install --save-dev prisma dotenv
import "dotenv/config";
import { defineConfig, env } from "prisma/config";

export default defineConfig({
  schema: "prisma/schema.prisma",
  migrations: {
    path: "prisma/migrations",
  },
  datasource: {
    url: env("DATABASE_URL"),
  },
});
```

## After Fixing

Once the files are updated, you need to rebuild the Docker image because the schema is baked into the image during build time.
